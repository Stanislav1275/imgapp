# Обработка изображений: практическая работа (Python + PySide6 + OpenCV)

Приложение с графическим интерфейсом к практической работе по курсу «Методы обработки сигналов и изображений».
Все вычисления лежат в папке `core/` и не зависят от окна, поэтому каждую функцию можно читать, запускать и проверять отдельно.

## Установка и запуск

```
pip install -r requirements.txt
python main.py             # запуск приложения
```

Нужен Python 3.10 или новее. Папка `samples/` с фотографиями и видео уже есть в проекте. При запуске сразу открывается пример;
свои файлы можно открыть кнопкой «Открыть…» (Ctrl+O) или перетащить мышью в окно.

**Удобства интерфейса:** меню «Примеры» (готовые фотографии), светлая и тёмная тема (запоминается), внизу виден цвет пикселя
под курсором, правая кнопка мыши по любой картинке сохраняет то, что на ней показано, при долгих операциях курсор меняется
на «ожидание», подсказки при наведении на ползунки.

Без окна (проверка и материалы для отчёта):

```
python run_demo.py                          # прогоняет все функции, результаты в demo_output/
python report/make_figures.py               # рисунки для отчёта (нужен matplotlib), результаты в report/figures/
python -m unittest discover -s tests -t .   # 76 автоматических тестов
```

## Как устроен проект

```
main.py               запуск окна
core/                 вся логика (без окна)
  imageio.py          чтение и запись файлов (внутри всегда RGB)
  info.py             сведения о файле: размер, разрешение, глубина цвета, формат
  colorspaces.py      перевод цвета: RGB, HEX, CMYK, HSV, HSL, YCbCr, LAB
  tone.py             серое, яркость, контраст, гамма, насыщенность, коррекция серого
  histogram.py        гистограммы (яркость, R, G, B)
  binarize.py         порог, метод Оцу, адаптивный порог
  morphology.py       эрозия, дилатация, открытие, закрытие, градиент
  filters.py          резкость, размытие в движении, тиснение, медиана, шум
  edges.py            границы: оператор Робертса, Canny
  features.py         ключевые точки: Харрис, SIFT, FAST
  similarity.py       поиск двух самых похожих изображений
  video.py            вычитание фона, размытие движущихся объектов
samples/              фотографии и видео для проверки (создаются файлом make_samples.py)
report/               скрипт рисунков для отчёта
gui/                  окно (только отрисовка и кнопки, вычислений нет)
  main_window.py      главное окно и вкладки
  theme.py            цвета и стиль (светлая и тёмная темы)
  widgets.py          показ картинки и гистограммы
  tabs/               по одной вкладке на файл
tests/                автоматические проверки
docs/color_formulas.md  вывод всех формул цветовых моделей и сжатия
```

**Порядок чтения кода для понимания:** `core/colorspaces.py` → `core/tone.py` → `core/histogram.py` → `core/filters.py` →
`core/morphology.py` → `core/edges.py` → `core/features.py` → `core/similarity.py` → `core/video.py` → `gui/`.
В каждом файле у функции есть описание: что она делает и откуда формула.

## Основные формулы

Подробный вывод — в `docs/color_formulas.md`. Здесь только то, что используется в яркостных преобразованиях
(r — яркость пикселя до, s — после, обе от 0 до 255):

| Операция | Формула | Нейтральное значение |
|---|---|---|
| Яркость | `s = r + β` | β = 0 |
| Контраст | `s = α · (r − 128) + 128` | α = 1 |
| Гамма | `s = 255 · (r / 255)^γ` | γ = 1 |
| Насыщенность | `c' = gray + k · (c − gray)`, `gray = 0.299R + 0.587G + 0.114B` | k = 1 |
| Бинаризация | `s = 255, если r > T, иначе 0` | — |

Ползунки переводятся в числа так: β = 2.55 · ползунок, α = 1 + ползунок / 100, γ = ползунок / 100.

## Откуда фотографии в samples/

Фотографии взяты из набора данных пакета scikit-image (`skimage.data`), файл `make_samples.py` их записывает в папку.
По документации scikit-image: астронавт — NASA (общественное достояние), кот и кофе — лицензия CC0, остальные
(монеты, ракета) — свободные изображения набора данных. Если будете публиковать проект, проверьте условия по
документации scikit-image. Видео `moving.avi` создаётся программно: на фото кота летит мяч и едет коробка.

## Договорённости в коде

- Изображение внутри программы — массив NumPy `(высота, ширина, 3)` типа `uint8` с каналами в порядке **R, G, B**.
  OpenCV хранит B, G, R, поэтому переворот каналов делается только при чтении и записи файла (`core/imageio.py`).
- Серое изображение — массив `(высота, ширина)`.
- Результаты всех операций обрезаются до диапазона 0..255 (`clip`), исходная картинка не изменяется.


## Сборка в запускаемый файл

Чтобы получить программу, которую можно открыть двойным щелчком (без `python main.py`):

```
source .venv/bin/activate
bash build_app.sh          # на Windows: build_app.bat
```

Результат появится в папке `dist/` (на macOS — `ImageApp.app`). Собирать нужно на той системе, для которой нужна программа.
